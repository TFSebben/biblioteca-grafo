# 🕸️ Grafo Conceitual da Biblioteca Acadêmica

Visualizador interativo do Grafo Neural e Conceitual da Biblioteca Acadêmica.

- 🌐 **Acesso Online (GitHub Pages):** [https://tfsebben.github.io/biblioteca-grafo/](https://tfsebben.github.io/biblioteca-grafo/)
- 📚 **Acervo:** 482 obras acadêmicas, 955 nós e 1.861 arestas conectando autores, eixos temáticos e conceitos.
- ⚡ **Tecnologia:** Gerado deterministicamente via sync-library / Vis-Network.
